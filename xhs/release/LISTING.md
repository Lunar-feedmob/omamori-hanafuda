- 体积：5.5 MB（官方上限 10 MB，建议 2 MB；超出部分是插画、日文字体和卡面）

## 权限

只勾「本地存储」：用来保存图鉴、御守和通关进度。

不需要相册、摄像头、麦克风或定位。振动反馈用平台的 `vibrateShort`（客户端 9.50+），不需要单独授权。

## 用到的平台能力

| 能力 | 用途 | 客户端版本 | 低版本时 |
|---|---|---|---|
| Storage JS API | 保存进度 | 9.46+ | 退回浏览器存储（可能丢失） |
| getWindowInfo | 避开右上角胶囊按钮 | 9.49+ | 用固定的顶部留白 |
| vibrateShort | 配对、翻错、通关时轻震 | 9.50+ | 不震动 |

不联网、不收集用户信息、没有广告和内购。

## 扫码预览时逐项确认

- [ ] 第一次点按后有声音（音乐和音效都在包内实时合成，没有音频文件）
- [ ] 配对时手机轻震
- [ ] 关掉小工具再打开，图鉴和通关进度还在
- [ ] 顶部按钮没有被容器右上角的胶囊按钮挡住
- [ ] 新用户打开是「本所怪谈」主题，第一局前有可跳过的练习庭
- [ ] 主页底栏的主题按钮能依次切换 13 个主题
- [ ] 最小的屏幕上第八庭（24 张牌）也能完整显示
